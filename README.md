# Dotfiles
Minimal configuration made for Arch linux using MangoWM.

## Main Programs
- MangoWM
- Mangobar
- Vicinae (Raycast-like Fuzzel Replacement)
    The config includes lines to remove the slow open and close animation.
- Alacritty
- Brightnessctl
- swaybg (background)

## Mangobar
A simple config that shows workspaces and window name on the left. The right side shows brightness, volume, battery, and date + time.

### extra
This has not been setup for use with multiple monitors (run on a laptop), so be sure to consult the mangowm docs for that.
